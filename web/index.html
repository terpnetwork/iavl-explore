This view

The circle is this node. Each ring inward is the next real level. A click reads that wedge. The center is depth this picture has not opened.

Words

Store
One named tree in the database.
Prefix
The bytes s/k:<store>/ in front of that tree.
Node
One record. An inner node has a left child and a right child. A leaf holds one key and one value.
Node height
How many levels sit under this node. A leaf has node height 0. This is not the chain block.
Block
The chain height saved with this version of the tree. IAVL calls it a version.
Leaves
How many keys sit under this node. The node stores this count. This page does not count the keys.
Hasher
The function that made the hash in the node. SHA-256 or BLAKE3.
Mounted
The running program loads this store name. Bytes can remain in the file when the name is not mounted.
Commit
The list of mounted stores for one block. A name outside that list is not part of the app hash.
